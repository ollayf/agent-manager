One engine for both skills

The upgrade skill has no separate executable. It drives archive-icloud/icloud_archive.py and the same store, locks, registry and readers.

A resumable migration

Keep each v1 row until its files are durably recorded. Recover interrupted steps. Upload waits defer a root move so it can be retried.

No layout surprises

Older repos keep empty folders in place until the park step. A taken _archive/ name is reported; --park-dir can select an available name.
